# Prajakta Pramod Dangat — AWS & DevOps Portfolio

A light/white glassmorphism portfolio inspired by the structure and visual language of the reference portfolio.

## Files

- `index.html` — portfolio content
- `style.css` — light glassmorphism design and responsive layout
- `script.js` — scroll reveal and mobile navigation
- `assets/profile.jpg` — profile photo
- `assets/Prajakta_Pramod_Dangat_DevOps_CV.pdf` — resume

## GitHub Pages

1. Create a new GitHub repository named `Prajakta-Portfolio`.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will publish the site at your Pages URL.
